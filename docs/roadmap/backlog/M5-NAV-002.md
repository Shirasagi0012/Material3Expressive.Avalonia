# WideNavigationRail

## Scope

Implement expanded/collapsed rail behavior, responsive layout, selection, keyboard/focus, and
automation.

## Exit criteria

Expanded and collapsed states preserve navigation state and have deterministic layout and
accessibility tests.

## Delivered contract

`MaterialWideNavigationRail` is the D013 XAML adaptation of AndroidX WideNavigationRail. It owns
direct `MaterialNavigationItem` instances and a two-way `SelectedIndex`; two-way `IsExpanded`
changes layout without replacing either. Read-only `ExpansionProgress` follows the upstream
DefaultSpatial spring and can reverse mid-flight. Items default to Collapsed→Top and
Expanded→Start while `FollowWideRailExpansion=False` keeps an explicit item position.

The collapsed rail is 96dp wide with 44dp vertical content padding, 64dp minimum top-icon items,
and 4dp spacing. Expanded layout grows intrinsically from 220dp through 360dp, uses 56dp-high
leading-icon indicators, LabelLarge, 16dp indicator padding, and zero item gap. Narrow parent
constraints are honored and the 220dp intrinsic width returns when space becomes available.
`Header` remains at logical start/top with the 40dp gap for Top arrangement;
`Arrangement=Top|Center|Bottom` implements the corresponding upstream placement.

Up/Down wrap through visible enabled destinations and coordinate focus with selection; Home/End
select endpoints and Tab remains ordinary desktop traversal. RTL mirrors logical-start header and
expanded-item placement. Automation is Tab + ISelectionProvider with stable real TabItem +
ISelectionItemProvider destinations, native header peers first, and ExpandCollapse on the rail.
Disabled destinations and disabled rails reject provider operations.

## Baseline and parity

Implementation and tests were reviewed against AndroidX `ff0a0a99` / Material3
`1.5.0-alpha25` `WideNavigationRail.kt`, `WideNavigationRailState.kt`, `NavigationItem.kt`,
`WideNavigationRailTest.kt`, `WideNavigationRailScreenshotTest.kt`, and the VERSION `v0_11_0`
collapsed/expanded/baseline/horizontal/vertical token files.

The pinned Compose Multiplatform Material3 `1.12.0-alpha03` / Jetpack `1.5.0-alpha22` producer
executes this API. Five formal scenes cover collapsed/expanded, light/dark, and disabled states.
All five pass the unchanged existing `navigation/` comparison profile as
`semanticRasterEquivalent`, with exact geometry/text contracts and zero rejected pixels. No
tolerance, warning, or compatibility behavior was added.
