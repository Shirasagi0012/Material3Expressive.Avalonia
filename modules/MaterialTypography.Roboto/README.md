# Roboto font for Material3Expressive.Avalonia

Bundles static, normal-width Roboto fonts for the weights used by Material3Expressive typography tokens: Regular (400), Medium (500), and Bold (700).

Register with `AppBuilder.WithRobotoFont()` and use `fonts:Roboto#Roboto`.
